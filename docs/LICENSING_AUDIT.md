## Scope and verification limits

The new [LICENSE](../LICENSE) reserves only rights actually owned by Notation Systems Inc. It preserves mandatory law, independently valid prior permissions, public-hosting permissions and third-party terms. It does not create a licence by passive browsing or impose automatic contractual penalties.

The inspected repository is public. [GitHub's current terms](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service), effective April 27, 2026, include public viewing/forking rights and rights for GitHub and its affiliates to use public content for specified AI development and training. The project notice preserves those platform grants; publishing it here cannot remove them. AI/TDM reservations are limited to rights the owner can lawfully reserve and require appropriate operational implementation for the publication system.

The owner's [declaration](OWNERSHIP_DECLARATION.md) establishes the instructed publishing identity for this task; it is not an assignment or independently verified title record. New incoming assets and contributions require creator/source/permission records before inclusion. Actual release packaging, signed licences, intended-market enforceability and any later third-party corpus distribution remain separate reviews.

The adoption changes documentation and a public licensing-request form. Runtime, schemas, scenario data, source register and validation code are preserved from the baseline. Content tests check repository consistency; they do not certify ownership, historical authenticity or enforceability.
